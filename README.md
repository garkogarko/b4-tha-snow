# B4 THA SNOW

A one-hole arcade golf game in a PS2-era style: rolling grassland, a flock of sheep, snow after your third shot, and a cutscene when you hole out.

**Play:** https://garkogarko.github.io/b4-tha-snow/

Controls: drag to aim, pull back to swing (mouse or touch). Space works on a keyboard.

The whole game is the single file `index.html`. `build.txt` points at the build to publish; pushing a change to it redeploys the site through `.github/workflows/deploy.yml`.
